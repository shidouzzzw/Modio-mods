Modio Admin

Buradan eklediğin her mod ve sunucu, GitHub reponu güncelleyip anında siteye düşer. Sunucular data/servers.json dosyasında tutulur.

1. GitHub Bağlantısı

Token sadece bu tarayıcıda (localStorage) saklanır, hiçbir yere gönderilmez. GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic), "repo" yetkisini işaretle.

2. Yeni Mod Ekle

Ana sayfa kartında ve öne çıkanlarda tüm alanı kaplar, yatay/geniş bir görsel kullan.
Boş bırakırsan büyük ikon küçültülerek kullanılır.
